# @four/text

Text and typography. Part of [four.js](../../README.md) — **scaffold only; no implementation yet.**

Unicode text with shaping, bidi, wrapping, rich spans, text on paths, and bitmap/SDF/MSDF rendering. Text is a core capability, not a UI afterthought.

Specification: §56 in [`docs/SPECIFICATION.md`](../../docs/SPECIFICATION.md).

- `src/` — implementation (strict TypeScript, ESM)
- `tests/` — unit tests (Vitest), colocated per package (§92)
