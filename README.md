# four.js

**One scene. Every dimension. Everything moves.**

four.js is a proposed unified JavaScript/TypeScript framework for building interactive
applications that combine 2D, 2.5D, and 3D graphics with animation, motion systems, and
physics (rigid-body, soft-body, and particle simulation) in a single shared scene model.

This repository currently contains the project's directory scaffold and specification
only — no implementation yet.
